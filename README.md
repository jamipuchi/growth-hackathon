# Space Party

Multiplayer 3D game where every player draws their own phone controller.

- Build plan: [PLAN.md](PLAN.md)

## Run

```
OPENAI_API_KEY=... node server.js
```

- Big screen: `http://<laptop-ip>:8000/space.html`
- Phones: `http://<laptop-ip>:8000/controller.html`

Node 20+, no dependencies. three.js loads from a CDN.
