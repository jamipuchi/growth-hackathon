## Notes per version

### v1.0-pre (first playtest, 22:50)
- Owner feedback: the ship must be drawn first (it becomes 3D); controls need tooltips; controllers must come from the
  drawing (they were mocked without a key); controller vs entity must be explicit; unlocks by drawing are key;
  players must be able to mess with each other; a lobby started from the big screen; much more space.
- Then a long Q&A fixed the design: see `PLAN.md` section 0.
- First real generation test (23:15): the owner drew a ship in the controller step → one giant button, and added
  buttons failed (output token limit). Hotfixed on the play server; generation-quality task queued.
